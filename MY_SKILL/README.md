# MY_SKILL

Reusable design + animation skills for building premium apps and websites with AI builders (Claude Code, Antigravity, Cursor, Lovable, Bolt, v0).

| Folder | What it is | Start here |
|---|---|---|
| `aura-design-system/` | AURA Premium UI: generic glossy, cinematic design system with Keka-style motion (tokens, components, motion, screens, platform code, prompts, live previews) | `aura-design-system/SKILL.md` |
| `in2it-brand-ui/` | AURA locked to the In2IT EBS "Converged Intelligence" brand: palette, fonts, official logo, In2IT post-login splash (Converge / Wash) | `in2it-brand-ui/SKILL.md` |
| `aura-design-system.zip`, `in2it-brand-ui.zip` | The same folders zipped for attaching to a chat | |

## Quick use
- Generic premium app: load `aura-design-system/SKILL.md`, paste prompt A from `aura-design-system/prompts.md`.
- In2IT EBS app or site: load `aura-design-system/SKILL.md` then `in2it-brand-ui/SKILL.md` (section 7 has the prompt).
- Claude Code: copy a folder into `~/.claude/skills/` (or a project's `.claude/skills/`) and it loads automatically for UI work.

## Live previews (open in a browser)
- `aura-design-system/preview/index.html` - home and search screens, dark mode, loading state, brand presets.
- `aura-design-system/preview/splash.html` - Keka-style post-login logo splash (comet wordmark + mark variant).
- `in2it-brand-ui/preview/splash-in2it.html` - In2IT EBS splash (Converge and Wash), white and navy backgrounds.
