# In2IT EBS brand UI skill

The AURA Premium UI design system locked to the In2IT EBS "Converged Intelligence" brand, plus the In2IT post-login splash animation.

- Needs the sibling folder `../aura-design-system` (same MY_SKILL folder).
- Start with `SKILL.md`. Open `preview/splash-in2it.html` in a browser to see the splash (Converge and Wash variants, white and navy backgrounds, dark mode, hold-on-loop).
- Web setup: link `../aura-design-system/foundations/tokens.css`, then `brand/tokens.in2it.css`, then load Google Fonts Newsreader + IBM Plex Sans.
- Logo files for every surface are in `brand/`. The splash animates the official PNG itself (sliced per letter with the table in `SKILL.md`), so the logo is always pixel-exact.

Use with Claude Code / Antigravity / Cursor: paste the prompt in `SKILL.md` section 7.
